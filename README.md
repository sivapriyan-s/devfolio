# DevFolio — Developer Portfolio

A clean, responsive personal developer portfolio showcasing core web projects and contact details. Built with semantic HTML5, modern CSS (Flexbox and CSS Grid), and deployed via GitHub Pages.

## Live Demo
* **Live Site:** [https://sivapriyan-s.github.io/devfolio/](https://sivapriyan-s.github.io/devfolio/)
* **Repository:** [https://github.com/sivapriyan-s/devfolio](https://github.com/sivapriyan-s/devfolio)

---

## Features
* **Semantic HTML5:** Built using `<header>`, `<main>`, `<section id="about">`, `<section id="projects">`, and `<footer id="contact">`.
* **CSS Grid & Flexbox:** Flexbox powers the navigation and contact rows; CSS Grid organizes the project showcase cards.
* **Responsive Design:** Mobile-first layout with a media query breakpoint that expands single-column project cards into multiple columns on larger screens.
* **Color & Type System:** Controlled with reusable CSS variables for consistent styling.

---

## Built With
* HTML5
* CSS3 (Custom properties, Flexbox, Grid, Media Queries)
* GitHub Pages (Static hosting)
